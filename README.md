# سَنَد — خطة طوارئ عائلتك

أداة ويب عربية مجانية تبني لكل عائلة خطة طوارئ مكتوبة في دقائق:

- أفراد العائلة ومعلوماتهم الطبية (فصيلة الدم، الحساسية، الأدوية)
- جهات الاتصال، مع "مركز أخبار" خارج المدينة
- ثلاث نقاط التقاء وكلمة سر عائلية لحماية الأطفال
- تعليمات مخصصة للمخاطر: زلزال، سيول، حريق، موجة حر، عاصفة رملية، انقطاع كهرباء، نزوح
- حقيبة طوارئ بكميات محسوبة حسب عدد الأفراد وأعمارهم وعدد الأيام
- خطة قابلة للطباعة + بطاقة جيب لكل فرد

كل البيانات تبقى في متصفح المستخدم (localStorage) ويمكن تصديرها واستيرادها كملف JSON. لا خوادم ولا تسجيل.

## التشغيل

موقع ثابت بالكامل: افتح `index.html` في المتصفح، أو انشره على GitHub Pages / Netlify دون أي إعداد.

# دوري — رفيقك لموعد الفيزا (`visa/`)

- **قائمة وثائق** حسب نوع التأشيرة (سياحة، زيارة عائلية، عمل، دراسة، علاج) والوضع المهني والسن، مع نسبة جاهزية الملف
- **موعدي:** عدّاد للموعد وجدول زمني لما يجب تجهيزه قبله، مع تحذير إذا كان السفر قريبًا جدًا من الموعد
- **حاسبة ٩٠/١٨٠ يومًا لشنغن:** أقصى مدة مسموحة لرحلتك المقبلة بناءً على إقاماتك السابقة
- **أسئلة المقابلة** الشائعة، و**تحذيرات من النصب** وباعة المواعيد

افتح `visa/index.html` في المتصفح.

## مراكز الفيزا في الجزائر (`visa/centers.html`)

موجّه للمقيمين في الجزائر: الجهة المعتمدة لكل سفارة (فرنسا، إسبانيا، إيطاليا، ألمانيا، بلجيكا، البرتغال، هولندا، النمسا، المجر، سويسرا، بريطانيا، كندا، الولايات المتحدة)، الولايات، الرابط الرسمي للحجز، وقواعد المواعيد والدفع. تصفية حسب شنغن/خارج شنغن والولاية. كل بطاقة موسومة «مؤكد» أو «تحقّق». البيانات في `visa/centers.js` (المصفوفة `CENTERS`) — حدّث تاريخ `CHECKED` عند كل مراجعة.
