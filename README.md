# 🇩🇿 دوري — رفيق الجزائريين لموعد الفيزا

موقع جزائري مجاني، دون تسجيل، وبيانات المستخدم تبقى في متصفحه فقط.

## الصفحات

| الصفحة | الملف | المحتوى |
|---|---|---|
| الرئيسية — أدوات الملف | `index.html` + `visa.js` | قائمة وثائق جزائرية حسب نوع التأشيرة والوضع (S12، CNAS، CASNOS، CCP…)، عدّاد الموعد وجدول التحضير، حاسبة ٩٠/١٨٠ يومًا لشنغن، أسئلة المقابلة، تحذيرات النصب |
| مراكز الفيزا في الجزائر | `centers.html` + `centers.js` | الجهة المعتمدة لكل سفارة (١٣ وجهة)، الولايات، الرابط الرسمي للحجز، قواعد الموعد والدفع |
| سَنَد — خطة طوارئ العائلة | `sanad/` | خطة طوارئ عائلية جزائرية: الحماية المدنية 14، الشرطة 17، الدرك 1055، الزلازل وحرائق الغابات والفيضانات، حقيبة طوارئ محسوبة، بطاقات جيب للطباعة |

التصميم مشترك في `styles.css`.

## تحديث دليل المراكز

البيانات في المصفوفة `CENTERS` داخل `centers.js`. عند كل مراجعة:
1. تحقّق من الجهة المعتمدة على موقع السفارة.
2. عدّل البطاقة وضع `status: "ok"` إن كان المصدر رسميًا، أو `"check"` إن لم يكن.
3. حدّث تاريخ `CHECKED`.

## التشغيل والنشر

موقع ثابت بالكامل: افتح `index.html` في المتصفح، أو انشره على GitHub Pages / Netlify دون أي إعداد.
